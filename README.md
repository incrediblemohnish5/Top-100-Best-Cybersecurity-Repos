# Top-100 Best Cybersecurity Repositories

This repository curates high-quality, open-source projects useful to security practitioners, researchers, students, and hobbyists. The goal is to collect the top security-related repositories across categories like offensive tooling, defensive tooling, network analysis, forensics, and CTF/learning resources.

Why this list
- There are thousands of security projects on GitHub. This list collects actively-maintained, well-documented, and widely-used repositories to help discovery.

Curation criteria
- Recent activity (commits, issues, PRs)
- Community signals (stars, forks, adoption)
- Documentation quality and usefulness
- Relevance to practitioners (tools, libs, datasets, tutorials)

How to contribute
- Open an issue to propose a repository (include owner/name, category, 1-line description, and link).
- Submit a PR adding entries under the appropriate category in REPOS.md using the template.
- Follow the coding of conduct and contribution guidelines in CONTRIBUTING.md.

Entry format
- owner/name — Short description — why it matters
